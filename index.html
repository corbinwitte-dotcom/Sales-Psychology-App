To get started with your guided visualizations:

Step 1: Add your audio files to the audio/ folder

Step 2: Edit audio/audio-files.json and list your files:

{
  "files": [
    "your-meditation.mp3",
    "another-meditation.mp3"
  ]
}

File Naming Tips:

  • Include keywords like "call", "meeting", "presentation", "confidence"
  • Example: morning-confidence-practice.mp3
  • Example: pre-sales-call-visualization.mp3
